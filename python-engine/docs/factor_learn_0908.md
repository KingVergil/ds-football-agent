### 3. 结论（保守）

1. **现行 N串1 单注票：38 天 0 中，ROI −100%**——确认票级在这个串长下不可用。
2. **"过M"系列的高 ROI 大部分是单日彩票**（07-25 一天占 95~100% 派彩），
   抽掉就翻符号；**不能据此上线**。
3. **唯一通过 leave-one-day-out 的是 `过4 + x≤1.20`**（全窗口 +138%、抽最好日仍 +68%）。
   但它要 5672 元投注（74 倍于基线）、只有 33/5672 = **0.58% 的中奖注率**，
   属高方差重尾策略；在 40 天样本 + 我扫了 16 个计划的情况下，
   **多重比较风险很高**，需要样本外验证。
4. **x_cap 的方向性证据**：`x≤1.15` 全负、`x≤1.18/+24%`、`x≤1.20/+11%`、`x≤1.25/1.30` 全负
   → **x 上限收紧到 1.18~1.20 之间似乎有价值**，但它的正收益也靠单日，不独立成立。
5. **观察型因子占 47~48%**，跨 45 天没有下降趋势——**"产生路径不对"是结构性的**，
   建议按 `DS_NO_SKIP_REFLECT=1` 做一次消融（关掉"无下单日造因子"）看腿级 ROI 是否改善。
