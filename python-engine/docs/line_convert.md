# 让球线换算（Poisson）与「让球盘到底有没有边际」

## 1. 为什么要换算

北单是**让球胜平负**（`goal_line` ∈ {-2,-1,0,+1,+2}）。但锐市场段里只有一部分盘口带
`公平盘「平均欧盘胜/平/负(<line>)」`，**主受让（gl>0）几乎完全没有**：

| 覆盖（能算出 x 的场次） | 修前 | 修后（Poisson 换算） |
|---|---|---|
| 全部 | 567 / 2108 = **27%** | **2104 / 2108 = 100%** |
| 平手 gl=0 | 1255 / 1258 | 100% |
| 主让 gl<0 | 644 / 645 | 100% |
| 主受让 gl>0 | **0 / 205** | **205 / 205** |

换算方法（`src/line_convert.py`，无 scipy 依赖）：去水 1X2 → 拟合两队 Poisson 均值 (λh, λa)
（粗网格 + 局部细化，≈9 ms/场）→ 任意让球线 L 下的三路概率
`H ⇔ (i-j)+L > 0`、`D ⇔ =0`、`A ⇔ <0`。

**精度对照**（换算 vs 同盘口「平均欧盘」，两者都有的 565 场）：三路概率平均绝对误差
**0.026**（line=-1: 0.026、line=-2: 0.027）。数量级上等价于"1~2 个百分点的盘口分歧"。
自检：line=0 往返一致；让球线单调（主让越多 H 越低）；三路和为 1（误差 <1e-9）。

## 2. 换算做完之后，让球盘有边际吗？——没有

用**换算后的市场 p̂** 重算 `x = 市场p̂ × 北单赛前赔率`，`y = E[开奖SP×1{中}]`（实测，按场聚类）：

| 类别 | x≥1.0 | x≥1.1 | x≥1.2 |
|---|---|---|---|
| **gl=0** | **1.183 [1.09,1.27]** n=1406 ✅ | **1.341 [1.19,1.49]** n=791 ✅ | 1.325 [1.11,1.55] n=415 ✅ |
| gl≠0 | 0.958 [0.85,1.06] ❌ | 0.959 [0.81,1.11] ❌ | 0.941 [0.75,1.13] ❌ |
| gl<0 主让 | 0.949 ❌ | 0.929 ❌ | 0.891 ❌ |
| gl>0 主受让 | 0.987 ❌ | 1.051 [0.73,1.37] ⚠️（n=120） | 1.072 [0.67,1.48] ⚠️（n=86） |

按 x 细分到每一档也一样：gl≠0 的 `x1–1.1 / 1.1–1.2 / 1.2–1.35 / 1.35–1.6 / ≥1.6`
点估计分别 **0.955 / 0.990 / 0.993 / 0.928 / 0.656**，没有任何一档 ≥1（唯一例外是 gl>0 的
1.2–1.35：1.385，但 n=47、CI [0.78,1.99]，说明不了问题）。

⇒ **「让球盘无边际」不是覆盖率或口径造成的，是真实结论。**

## 3. 两个前置校验（排除数据口径问题）

1. **开奖 result 就是「让球后」结果**：用「比分 + goal_line」反推对照官方 result，
   **2001 场 100% 一致**（gl=0 1322/1322、gl<0 511/511、gl>0 168/168）→ 上一轮怀疑的
   「口径不一致」被排除。
2. **回放档位拼接正确**（2026-07-11，周六两波）：

   | 波次 | 解析场次 | 档位分布 | prompt 内联数据段 == 该波次切片 |
   |---|---|---|---|
   | 16:30 | 21 | pass_6_hours 15 / pass_12_hours 4 / pass_1_day 2 | **21/21** |
   | 20:30 | 12 | pass_6_hours 10 / pass_12_hours 1 / pass_1_day 1 | **12/12** |

   同一天里不同比赛读不同档位（正是回放专用 data-manager 的设计），且**同一场比赛在不同波次
   会切换到不同档位**（Lota4459810：16:30 用 pass_1_day → 20:30 用 pass_12_hours）；prompt
   里内联的段落与那一波的切片逐字节相同。**0 次回退**。

## 4. 由此确定的分工（满足"所有场次都要进分析"）

* **分析（prompt）：全部场次进场**，每场都带上换算后的 `x`（现在 100% 可算）——LLM 看得到
  所有盘口（含让球）的错价情况，可以自己判断"这条腿 x 高但我不信"。
* **下注（引擎门）：只放行有证据的腿**（当前 = gl=0 且 x ≥ θ）。让球腿可以进 prompt、进观察
  （shadow 记录），但**没有证据前不下注**——这正是"一轮一轮验证"的方式。
* 待验证的观察档：`gl>0 且 x∈[1.2,1.35]`（点估计 1.385、n=47）——建议先用 shadow 模式累积样本。
