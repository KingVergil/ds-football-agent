# A/B 对照：注入 26 因子库 vs 空因子库（同期回放）

> 目的：回答「并行 init 产出并注入的因子库，到底有没有让回放变好」。
> 口径：同沙箱模型、同窗口、同门策略（θ=1.1 / gl0 / m_star=3 / config_default）、
> 同模型（deepseek-v4-pro），唯一差异 = 起始因子库（26 个 vs 0 个）。
> 生成：`python3 -m scripts.compare_arms /tmp/beidan_seq_bcl狗 /tmp/beidan_seq_control --labels "注入26因子,空因子库"`

## 窗口与执行

两臂的因子都会在回放中**自己生长**（反思产出新因子）——A 臂起点是 26，B 臂起点是 0。

## 怎么读

1. **没有任何一项指标显示注入因子带来改善**：命中率 −8.6pt、腿级 ROI −15.5pt，
   而两臂选择的档位质量几乎相同（平均 x 1.211 vs 1.210、平均 SP 3.15 vs 3.18）。
   ⇒ 注入因子**没有改变"选多便宜"**，却把**方向命中率拉低了**。
2. **但统计上不显著**：命中率差 z=−1.09（|z|>1.96 才是 5% 显著），
   腿级 ROI 的置信区间在 n=67/78 时极宽。**结论应为"未证实有益，且有不小的变差嫌疑"**，
   不能升级为"已证实有害"。
3. **票级两臂都是 0/10 中、−100%**：这符合 9 关票的方差（期望中票数 < 0.4 张），
   **票级不能作判据**（见 `beidan_ledger_status.md` §3.4）；判据只有腿级。
4. **D 侧在两臂都是正回报**（+21.4% / +38.9%），A 侧两臂都为负——方向结构一致，
   差异主要来自命中率整体下移，而非某一侧被带偏。

## 结论与建议

* **并行 init 的 26 因子库，按当前注入方式与口径，"未证实有用"，倾向有害。**
  这与 `cold_start_factor_init.md` §8 的预判一致：并行 init 得到的是**词汇表**，
  不是统计可用的因子库（26 个因子里没有一个跨日复现）。
* 下一步建议按此顺序试：
  1. **不注入**先跑更长窗口（纯自生长臂）——当前 B 臂表现最好，先把它跑厚；
  2. 注入时**只注入有真实样本的因子**（{样本≥2 且 盈亏>0} 的子集），
     现在 26 个里有大量 `样本=1 / 盈亏=0` 的观察型因子（它们只贡献噪声）；
  3. 把 `x_cap=1.45` 上沿收紧再对照（A 侧高 x 腿在两臂都是最亏的一档）。
* ⚠️ 单次 12 天对照不足以定论；**任何结论都要再复现一次**（换窗口或换种子）。

## 追加：根因诊断 —— 反思因子的**产生路径**不对（2026-09-11）

对照结果指向的不是"注入太多"，而是**因子的来源本身有问题**。按样本来源拆开两臂：

| | 注入臂 | 空库臂（自生长） |
|---|---|---|
| 因子总数 | 34 | 16 |
| **纯观察型（没有任何真实下单样本）** | **13 个** | 4 个 |
| 观察样本条数（hit=None / profit=0，不参与盈亏） | 50 | 22 |
| 真实样本条数 | 55 | 47 |
| 观察样本占比 | **48%** | 32% |
| **真实样本的盈亏** | **+9.06** | **+5.78** |

### 两个硬事实

**① 一半的"知识"来自狗没下过注的场次。**
`settle()` 在无结算单时走 `_reflect_skipped()`：随机取 6 场 + 按赛前离散分层取 5 场
**完场但本狗没下单**的比赛，标成 `hit=None / profit=0`（正确：不给假收益），
然后让 LLM 在这些数据上"找模式"并命名成因子（`alpha_factors` 通道）。
这些因子**从来没有被任何真实决策验证过**——它们是对既成事实的事后归纳，
不是"这条规律值不值得买"的证据。注入臂里 13/26 个就是这样来的。

**② 有真实样本来历的因子反而是赚钱的。**
两臂的**真实样本**盈亏都是**正的**（+9.06 / +5.78），命中 23/32 与 21/26
（≈72% 与 81% 的方向正确率——注意这是**被归因到的那一侧**，口径是"归因正确率"，
不等于选腿命中率）。也就是说：**真金白银验证过的那条路径产出的是有效信号，
而观察型路径产出的是噪声**，两者混在同一个 `factor_perf` 里、一起进 prompt、一起参与校准。

### 为什么会拉低成绩

注入臂与空库臂的**档位质量完全相同**（x̄ 1.211 vs 1.210、SP̄ 3.15 vs 3.18），
差异 100% 落在**方向命中率**（29.9% vs 38.5%）。机制上最合理的解释：
观察型因子进了 prompt 的"因子清单"，LLM 为"用上某个因子"而改选边，
而那些因子本就没有选择性——等于给方向判断加了噪声。

### 已验证的关断开关

新增 `DS_NO_SKIP_REFLECT=1`（`BeidanParlayDog._reflect_skipped` 开头）：
关闭"无下单日造因子"这条路径，只保留"真下单 → 结算反思归因"的来源。
用它跑第三臂（同窗口、同 0 因子起点）即可单独验证这条路径的净影响。
