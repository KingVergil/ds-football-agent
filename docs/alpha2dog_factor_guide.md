# alpha2狗 因子判断准则（引导词版）

> 基于 alpha2狗 2026.06—07 实盘 60+ 场投注的因子回测数据提炼。每条因子标注历史胜率与累计回报，供结合足球数据提示词做辅助判断。

---

## 一、核心决策框架

alpha2狗 的决策遵循 **"三要素共振"原则**：

```
离散凝聚 + 赔率同向 + 盘口保护 → 出手
任意一环缺失或背离 → 降仓或跳过
```

**数据验证口诀**：离散、赔率、资金，三选二同向才能过。

---

## 二、强正向因子（买入信号）

以下因子历史胜率 ≥ 80%，是核心做单依据。

### 1. 离散凝聚深盘顺向 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 35 次 |
| 命中率 | **100%**（胜 22 / 负 0 / 走 13） |
| 累计回报 | +5,083 |

**判断准则**：
- 离散在某方（通常为让球方）极度凝聚至低位，对立方向离散高企封杀
- 亚盘维持半一以上深盘，水位中低或平稳
- 欧赔在该方向同步下沉更佳（非必须）

**操作**：此为最强信号，可满凯利（单注 15%）下注。

### 2. 深盘连续升盘低水 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 11 次 |
| 命中率 | **100%**（胜 11 / 负 0 / 走 0） |
| 累计回报 | +3,272 |

**判断准则**：
- 深盘（半一以上）在受注过程中连续升盘
- 升盘同时水位维持在中低水（≤0.94），形成"盘升水不升"的保护结构
- 机构主动加设门槛并控制赔付，正视上盘打穿

**操作**：可满凯利下注。

### 3. 深盘低水保护 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 11 次 |
| 命中率 | **100%**（胜 8 / 负 0 / 走 3） |
| 累计回报 | +2,327 |

**判断准则**：
- 深盘搭配极低水位（≤0.85）提供赔付保护
- 机构降低上盘风险，多为穿盘信号
- 即使走水也不亏本金

**操作**：安全边际高，可满凯利。

### 4. 离散凝聚低水保护 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 12 次 |
| 命中率 | **100%**（胜 8 / 负 0 / 走 4） |
| 累计回报 | +2,304 |

**判断准则**：
- 离散在某方极度凝聚
- 同时该方赔率水位处于中低水（≤0.90）
- 形成"离散共识 + 机构防范"双重保护

**操作**：可满凯利。

### 5. 离散极度凝聚追强 ⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 1 次（新兴因子） |
| 命中率 | **100%** |
| 累计回报 | +289 |

**判断准则**：
- 离散在某一方极度凝聚（接近冰点值 <0.5）
- 另一方离散高企封杀
- 必发资金或欧赔同向支撑

**操作**：信号强但样本少，建议 1/4 凯利。

### 6. 深盘升盘低水不热 ⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 1 次（新兴因子） |
| 命中率 | **100%** |
| 累计回报 | +314 |

**判断准则**：
- 深盘升盘并维持低水
- 未出现过度受热迹象（必发无大规模卖盘堆积）
- 机构防范上盘意图明显

**操作**：信号强但样本少，建议 1/4 凯利。

## 三、特殊场景因子

### 7. 退盘离散凝聚上盘 ⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 多次实战验证 |
| 命中率 | 高 |

**判断准则**：
- 亚盘退盘示弱（如从一球退至半一）
- 但离散在让球方依然凝聚不散
- 退盘是机构诱下的掩护动作，上盘仍可打出

**操作**：退盘 + 离散不散 = 上盘可追。但若退盘后离散也散了，则放弃。

### 8. 赔率下沉离散凝聚 ⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 4 次 |
| 命中率 | 高（胜 1 / 走 3，无负） |
| 累计回报 | +653 |

**判断准则**：
- 欧赔低赔方持续下沉（非孤立跳动，需持续走低）
- 同时离散在该方向极度凝聚
- 对手方向离散高企

**操作**：赔率 + 离散共振，正路信号。

### 9. 离散分化封杀冷门 ⭐
| 指标 | 数值 |
|------|------|
| 样本 | 7 次 |
| 命中率 | 约 50% |
| 累计回报 | +458 |

**判断准则**：
- 需同时满足"目标离散极低 + 对立离散极高"的双向条件
- 单一方向凝聚不够
- 需配合赔率下沉和盘口保护

**操作**：不可单用，必须与其他因子共振。

### 10. 平离散反差博平 ⭐
| 指标 | 数值 |
|------|------|
| 样本 | 2 次（新兴） |
| 命中率 | 50% |

**判断准则**：
- 平局离散相对主客离散极低
- 必发平局买盘 > 卖盘（资金主动介入平局）
- 平赔稳定

**操作**：小注博平，不可重注。

## 四、风险警示因子（卖出/回避信号）

以下因子是"反向指标"，触发时意味着前面正向因子的信号可能失效，应降仓或跳过。

### 🚫 1. 离散异常凝聚诱盘警示
| 指标 | 数值 |
|------|------|
| 样本 | 19 次 |
| 命中 | 仅 4 次正向，14 次翻车 |
| 累计亏损 | **-3,692** |

**判断准则**：
- 离散异常凝聚在错误方向（如弱势方/受让方）
- 或极度凝聚但与赔率水位走向背离
- 单一离散凝聚不足以支撑下注

**操作**：⚠️ 这是 alpha2狗 最大亏损来源。触发此因子时，即使其他正向因子共振，也必须降仓至正常仓位的 1/2 或直接跳过。

### 🚫 2. 离散极低凝聚诱杀
| 指标 | 数值 |
|------|------|
| 样本 | 3 次 |
| 命中 | 0 胜 / 3 负 |
| 累计亏损 | -565 |

**判断准则**：
- 离散在某一方极度凝聚（接近冰点）
- 但资金背离或赔率停滞不跟
- 市场过热形成诱杀

**操作**：直接跳过，或反向操作。

### 🚫 3. 离散凝聚赔率不下沉
| 指标 | 数值 |
|------|------|
| 样本 | 1 次 |
| 命中 | 负 |

**判断准则**：
- 离散在某一方极度凝聚
- 但欧赔未同步下沉，亚盘水位反而上升
- "凝聚-停滞背离"，预示上盘过热易翻车

**操作**：跳过或降半仓。

### 🚫 4. 升盘离散不凝聚
| 指标 | 数值 |
|------|------|
| 样本 | 1 次 |
| 命中 | 负 |

**判断准则**：
- 亚盘升盘 + 资金同向
- 但离散未在该方向凝聚
- 常为诱盘，上盘不稳

**操作**：跳过。

### 🚫 5. 资金离散背离预警
| 指标 | 数值 |
|------|------|
| 样本 | 1 次 |
| 命中 | 负 |
| 亏损 | -350 |

**判断准则**：
- 必发资金净流向与离散凝聚方向相反
- 或买卖盘结构异常

**操作**：这是强力反向信号，触发即跳过。

### 🚫 6. 离散低位陷阱
| 指标 | 数值 |
|------|------|
| 样本 | 1 次 |
| 命中 | 负 |
| 亏损 | -350 |

**判断准则**：
- 非目标方向离散呈现极端低位凝聚
- 但目标方向离散未同步收紧
- 资金或赔率出现背离

**操作**：跳过。

### 🚫 7. 平离散高企防平
| 指标 | 数值 |
|------|------|
| 样本 | 2 次 |
| 命中 | 0 胜 / 1 负 / 1 走 |

**判断准则**：
- 离散值中平局离散异常高企
- 看似封杀平局，但强队离散优势不足时仍可能出平

**操作**：触发后降仓，不可满注追强队穿盘。

## 五、实操决策流程

```
Step 1: 离散结构扫描
├── 目标方向离散是否极度凝聚（低位）？
├── 对立方向离散是否高企封杀？
└── 平局离散是否合理（不高不低）？

Step 2: 赔率趋势验证
├── 欧赔目标方向是否持续下沉？
├── 下沉是否具有连续性（非单次跳动）？
└── 是否存在"凝聚但赔率停滞"的背离？

Step 3: 盘口结构确认
├── 盘口深度是否与实力差匹配？
├── 水位是否中低（≤0.94 为佳）？
├── 升盘是否伴随降水（盘升水不升）？
└── 退盘是否离散不散？

Step 4: 资金流向交叉验证
├── 必发净流向是否与离散方向一致？
├── 是否存在买卖盘严重背离？
└── 资金背离时，其他信号降权

Step 5: 仓位决策
├── 三要素（离散+赔率+盘口）全部共振 → 满凯利 15%
├── 两要素共振，资金中性 → 1/2 凯利 7-10%
├── 仅离散凝聚，赔率/盘口无共振 → 1/4 凯利 3-5% 或跳过
├── 触发任一风险警示因子 → 降半仓或跳过
└── 凯利公式 f = (b×p - q)/b，实际仓位 = f × 0.25
```

## 六、关键数据字段速查

使用足球数据 API 时，重点关注的字段：

| 字段 | 用途 | 关键阈值 |
|------|------|---------|
| `discrete-odds` 离散值 | 判别市场共识方向 | 目标方向 <5 为强凝聚，<1 为冰点；对立方向 >30 为封杀 |
| `eu-odds-pinnacle` 欧赔 | 判别赔率趋势 | 持续下沉 ≥0.05 为有效信号 |
| `asian-handicap-pinnacle` 亚盘 | 判别盘口保护 | 水位 ≤0.85 为低水保护；升盘+水不升为强信号 |
| `fair-odds` 公平盘 | 判别实力差 | 实力差 ≥1.0 可支撑深盘穿盘 |
| `betfair-buysell` 必发 | 判别资金共识 | 净买入方向与离散方向一致为同向 |

## 七、一句话总结

> **离散凝聚是筛子，赔率下沉是确认，盘口保护是安全带。三者同在才重注，缺一不可满仓。离散凝聚在错的方向或没有赔率跟随时，是最大的陷阱。**
