# bc狗 · 因子「方向型/预警型」判断 — 在分析 prompt 里由 LLM 判断（v1）

> 用途：10:30 附近跑一次 dry-run 分析后，对照本文件自查「因子性质判断」是否生效。
> 原则：不做 hard code / 关键词检测（视同过拟合），改用 LLM prompt 段落判断因子性质。

## 1. 为什么加

因子库的「📈顺向」是按回报符号（正收益）分的，但里面混了两种性质：
- ① 给出明确方向（主胜/客胜/平某一侧）→ 可作单选方向。
- ② 只提示风险/波动/爆冷、需要防冷或全包 → 不能单选，只能进全包。

之前想用关键词硬判（如名字含"全包/防冷"→预警型），被否。现在改为：在分析 prompt 里放一段判断说明，让 LLM 用它前先读描述判性质。

## 3. 加进 prompt 的段落（原文）

```
## 🧭 因子性质判断（重要：用之前先判断，不要按名字/关键词套）
- 用每个因子前，先读它的描述判断性质：
  ① 它给出明确可下注方向（主/客/平某一侧）→ 可作单选方向，但仍需离散/资金/盘口同向。
  ② 它只提示风险/波动/爆冷、需要防冷或全包 → 只能进全包/防冷，绝不拿去单选。
- 🔄反向（负回报）→ 一律规避或全包，绝不单选。
- 判断依据是「用它会给你一个方向，还是只提醒你小心」。读描述语义判断，不要按因子名套用。
```
