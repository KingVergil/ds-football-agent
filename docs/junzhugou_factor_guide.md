# 均注狗 因子判断准则（引导词版）

> 基于均注狗 2026.06—07 实盘 214 场投注的因子回测数据提炼。每条因子标注历史胜率与累计回报，供结合足球数据提示词做辅助判断。

---

## 一、核心决策框架

均注狗的决策遵循 **"全覆盖执行"原则**：

```
每场比赛 → 必须下注 → 固定 2% 仓位 → 亚盘 H 或 A
```

**三条铁律**：
1. **每场必下**。不允许 skip，不允许观望。
2. **只投亚盘**。不碰胜平负、大小球。
3. **信号矛盾时，选赔率更高的一方**（高赔 = 高回报）。

---

## 二、强正向因子（方向信号）

以下因子触发时，凝聚/下沉/低水方向即为投注方向。

### 1. 离散凝聚低水保护 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 26 次 |
| 命中率 | **96%**（胜 24 / 负 1 / 走 1） |
| 累计回报 | +562 |

**判断准则**：
- 离散在某一方极度凝聚至低位
- 同时该方亚盘水位处于中低水（≤0.90）
- 形成"市场共识 + 机构防范"双重确认

**操作**：凝聚且低水方 = 投注方向。最可靠的均注狗因子。

### 2. 离散异常收敛 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 9 次 |
| 命中率 | **100%**（胜 8 / 负 0 / 走 1） |
| 累计回报 | +209 |

**判断准则**：
- 某一方离散在收盘前持续收紧至极低值
- 平局离散和对立方向离散同步高企发散
- 形成"一收两散"的明确指向

**操作**：离散持续收敛方 = 投注方向。

### 3. 实力碾压方向下沉 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 24 次 |
| 命中率 | **91%**（胜 21 / 负 2 / 走 1） |
| 累计回报 | +484 |

**判断准则**：
- 公平盘实力差巨大（≥1.0），强队明确
- 欧赔严重向强队倾斜并持续下沉
- 亚盘深盘跟随（半一以上）

**操作**：强队方向 = 投注方向。深盘有走水风险，但均注模式下不影响整体正期望。

### 4. 赔率下沉离散凝聚 ⭐⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 17 次 |
| 命中率 | **88%**（胜 14 / 负 2 / 走 1） |
| 累计回报 | +265 |

**判断准则**：
- 欧赔在某一方持续下沉（非单次跳动，需有连续性）
- 同时离散在该方向极度凝聚
- 赔率趋势与离散结构共振

**操作**：下沉+凝聚方 = 投注方向。

### 5. 主胜赔大幅下沉 ⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 10 次 |
| 命中率 | **86%**（胜 6 / 负 1 / 走 3） |
| 累计回报 | +109 |

**判断准则**：
- 主胜欧赔在收盘阶段出现非理性大幅下沉
- 机构真实防范主胜打出
- 需区分"自然下沉"与"非理性跳水"

**操作**：投主队 H。

### 6. 升盘不降水即上盘 ⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 9 次 |
| 命中率 | **83%**（胜 5 / 负 1 / 走 3） |
| 累计回报 | +110 |

**判断准则**：
- 亚盘升盘（如半球→半一）
- 升盘后上盘水位维持中高不下调
- 高水制造阻买心理障碍，实为保护上盘

**操作**：上盘方向。注意区分：升盘+大幅降水可能是真热，需警惕。

### 7. 离散逆赔跟低赔 ⭐⭐
| 指标 | 数值 |
|------|------|
| 样本 | 9 次 |
| 命中率 | **75%**（胜 6 / 负 2 / 走 1） |
| 累计回报 | +102 |

**判断准则**：
- 离散极值方向与欧赔低赔方**矛盾**
- 这是关键：离散说 A 方向好，但赔率低在 B 方向
- 此时坚决跟随低赔方

**操作**：低赔方 = 投注方向。离散和赔率打架时，信赔率——机构真金白银不会说谎。

## 三、辅助因子（信号不明时参考）

### 8. 乱流跟强队
| 样本 | 4 次，胜 3 / 走 1，无负 |

**判断准则**：离散、赔率均无明确方向时，跟随实力稍优或低水保护方。

### 9. 离散低位凝聚正路
| 样本 | 3 次 |

**判断准则**：主胜离散异常低位凝聚 + 平客离散高企 → 跟主队，无视水位高低。

### 10. 平赔凝聚防上盘
| 样本 | 3 次，胜 2 / 负 1 |

**判断准则**：平局离散急剧收敛至极低位，主客离散高企 → 上盘不稳，转投受让方。

### 11. 反常水位追弱势方
| 样本 | 2 次 |

**判断准则**：实力优方水位高企，弱势方反而低水 → 机构真实防范弱势方，跟低水弱势方。

### 12. 离散凝聚高水正路
| 样本 | 1 次（新兴） |

**判断准则**：离散在某一方极度低位凝聚，即使水位高企（≥1.00），仍可无视高水追正路。

## 四、矛盾局处理（独家机制）

均注狗最重要的差异化规则：**当所有因子都无法明确指向 H 或 A 时，选赔率更高的一方。**

```
信号指向 H → 下 H
信号指向 A → 下 A
信号矛盾 / 无信号 → 比较赔率，选高赔方
```

这并非"乱猜"——均注模式下，高赔方的赔率优势会在大量重复中兑现为正向期望。即便这个子策略本身不盈利，它保证了你永远不下错方向（因为你没有跳过这场比赛）。

## 五、风险警示信号

以下信号本身不给方向，但提示降权或反向参考：

- **离散过热翻车**：离散极度凝聚但欧赔未同步下沉 → 凝聚方易翻车，可考虑选对立高赔方
- **离散极端凝聚易翻车**：离散值 <0.5 冰点 → 市场过热，上盘打出概率降低
- **必发抛压防上盘**：必发卖盘 >> 买盘 → 即使离散看好也需谨慎
- **离散平局凝聚防上盘**：平局离散远低于主客胜 → 防平局，转投受让方

## 六、实操决策流程

```
Step 1: 扫描正向因子
├── 有明确正向因子触发 → 因子方向 = 投注方向 → 下单 2%
├── 多个因子同向共振 → 信心增强但不改仓位（仍为 2%）
└── 无正向因子触发 → 进入 Step 2

Step 2: 自主数据判断
├── 离散凝聚在某一方？→ 跟凝聚方
├── 欧赔大幅下沉某方向？→ 跟下沉方
├── 亚盘低水保护某方？→ 跟低水方
├── 实力差明显？→ 跟强队
└── 以上全无 → 进入 Step 3

Step 3: 矛盾搏高赔
├── 比较 H 和 A 的赔率
├── 选赔率更高的一方
└── 固定 2% 仓位，执行
```

**仓位管理**：雷打不动 2%。不因连赢加仓，不因连亏缩量。

## 七、关键数据字段速查

| 字段 | 优先级 | 用法 |
|------|--------|------|
| `discrete-odds` 离散值 | ★★★ | 看哪个方向离散最低——市场共识方向 |
| `eu-odds-pinnacle` 欧赔 | ★★★ | 看哪个方向赔率在持续下沉——机构防范方向 |
| `asian-handicap-pinnacle` 亚盘 | ★★☆ | 水位 ≤0.85 有保护，≥1.00 需警惕 |
| `fair-odds` 公平盘 | ★★☆ | 实力差 ≥1.0 可果断跟强队 |
| `betfair-buysell` 必发 | ★☆☆ | 辅助验证资金是否与离散同向 |

## 八、一句话总结

> **每场必下、固定 2%、只做亚盘。离散指向、赔率确认、低水保护——有信号跟信号，没信号选高赔。不跳过任何一场，用绝对执行换长期正期望。**
