## 一、强队穿盘信号（核心利润来源）

### 1. 实力碾压型
**公平盘实力差 + ELO 双重碾压时，忽略盘口深度，直接追强队。**
底层逻辑：机构开出深盘是在防范而非诱盘。实力差距大到一定程度，水位和离散的短期波动都是噪音。
- 实力差碾压 (23次 19W/2L/2P +30,161)
- 公平盘进球碾压 (8次 6W/2L +3,522)：预期进球差 ≥ 3球时上盘极其明确

### 2. 深盘 + 低水保护型
**让球 ≥ 1球 + 上盘水位 ≤ 0.95 → 机构在压低赔付，强队穿盘概率极高。**
底层逻辑：深盘低水 = 庄家不敢给高水吸引筹码，真实看好上盘。
- 深盘低水保护 (15次 14W/0L/1P +28,082)
- 升盘低水示强 (4次 3W/0L/1P +11,678)：盘口升深 + 水位始终中低 = 真实示强

### 3. 离散极端分化型
**让球方离散极致凝聚 + 受让方离散异常放大 → 上盘大概率穿盘。**
底层逻辑：离散凝聚 = 市场一致看强，离散放大 = 无人敢接弱队。
- 上盘凝聚下盘高散 (5次 5W/0L +12,521)
- 离散客胜极高 (18次 14W/1L/3P +16,807)：客队离散极高 = 爆冷概率极低
- 离散弱方极高 (3次 3W/0L +3,686)

### 4. 赔率 + 离散共振型
**欧赔胜赔持续下沉 + 离散凝聚同向 → 机构放弃防范，坚决追强。**
底层逻辑：赔率变化 + 离散变化同时指向同一方向 = 信号可信度翻倍。
- 离散极值共振上盘 (2次 2W/0L +7,715)
- 欧赔碾压离散共振 (2次 2W/0L +7,098)
- 赔率下沉追强 (2次 2W/0L +8,950)

## 二、避坑信号（止损来源）

### 5. 深盘高水 = 穿盘癌
**让球 ≥ 1球 + 上盘水位 ≥ 0.95 → 强队大概率赢球输盘。**
底层逻辑：深盘高水 = 机构给赔付空间，是在诱上盘而非防上盘。
- 深盘高水是穿盘癌 (2次 0W/0L/2P -6,000)

### 6. 欧赔下沉 + 深盘高水 = 矛盾信号
**欧赔下沉看强 + 但盘口高水 → 机构对穿盘无信心，退让或放弃。**
- 赔率下沉深盘高水 (7次 3W/1L/3P -6,885)

### 7. 浅盘低水诱盘
**大小球 ≤ 2.5 + 大球中低水 → 多为诱大，真实方向小球。**
- 浅盘低水诱大球 (3次 0W/2L/1P -1,200)

## 三、大小球信号

### 8. 升盘压制大球
**亚盘升深 + 大小球浅盘 → 比赛趋于收缩，小球可期。**
- 升盘压制浅盘大球 (3次 1W/1L/1P +760)
- 降盘高水小球 (2次 1W/0L/1P +345)

### 9. 离散平局凝聚 → 小球
**平赔离散极低 + 胜负离散同步放大 → 平局+小球格局。**
- 离散平局凝聚小球 (4次 2W/0L/2P -775)

## 实战判断流

```
看比赛 → ① 实力差大不大？
         → 大 → ② 盘口深不深？（≥1球）
                → 深 → ③ 水位低不低？（≤0.95）
                       → 低 → 🔥重注强队穿盘
                       → 高 → ⚠️ 警惕赢球输盘，降仓或放弃
                → 浅 → ④ 离散是否极端分化？
                       → 凝聚+放大 → 追强队
                       → 平淡 → skip
         → 小 → ⑤ 平赔离散是否极低？
                → 是 → 考虑平局/小球
                → 否 → skip
```
