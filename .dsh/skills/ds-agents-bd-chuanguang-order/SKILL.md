# 北单串光票 → okooo 点选 → 斗狗场「bc狗」

串光票 = 一张 8串1：**3 个胆（单选腿，全串胜负手）+ 5 个全包腿（3&1&0）**，
注数 = 3^(全包腿数)（5 全包 = 243 注 × 2 元 = 486 元）。

**点选动作发生在 okooo.com/danchang 页面上**（每行三个赔率链接 = 胜平负按钮），
不要在斗狗场点 ⚡ 分析（那是狗自己分析选腿，不是按票点选）。

## 票格式解析（先解析，再点选）

每行格式：

```
序号 期号_编号 主队 vs 客队 · 联赛 让球 胆/选择 赔率列表
1    26091_33   科尔多瓦学院 vs 圣洛伦索 · 阿甲  平手  胆3    3@2.01
6    26091_22   阿斯顿维拉 vs 阿森纳 · 英超      受让1  3&1&0  3@6.9 & 1@4.33 & 0@1.6
```

| 字段 | 规则 |
|---|---|
| 编号 | `26091_33` = 期 26091 + 北单编号 33；`_21` 就是编号 21。**编号 = 页面行号，定位的唯一键** |
| 让球 | 主队视角：平手=0 / 受让1=+1 / 让1=-1 / 让2=-2 … |
| 选择 | `胆3`=单选主胜且**定胆**；`3&1&0`=全包；`3&1`/`1&0`=双选；`1`/`0`=单平/单客 |
| 赔率 | `3@2.01 & 1@5.21 & 0@6.45` = 让球胜平负 SP（北单） |

## 在 okooo 页面点选（核心步骤）

1. 打开 https://www.okooo.com/danchang/（默认当前期；已截止场次勾「显示已截止比赛」查看）。
2. 按票面编号定位行（页面行号 = 北单编号）。
3. **点赔率 = 选胜平负**：行内三个可点赔率链接分别是 主胜/平/客胜（3/1/0）：
   - `胆3` → 只点**主胜**那个赔率；
   - `3&1&0`（全包）→ 三个赔率**全部点一遍**；
   - 受让/让球行照点（盘口在票面上已注明，页面行内 (+1)/(-1) 即盘口）。
4. **设胆（胆腿最后一步）**：行内主/平/客赔率之后的 checkbox 就是「设胆」列——
   点选赔率后该 checkbox 从 disabled 变可勾，**对胆腿（单选腿）勾上它**；
   全包腿不勾。
5. **已选验证（看已选即可）**：点中的赔率格变红/高亮 = 已选；勾上的 checkbox = 设胆。
   逐腿核对 编号/让球/胆或全包一致。
6. 点完 8 腿（3 胆勾设胆 + 5 全包）即一张 8串1（5全包+3单选，243 注）成型，
   把票交斗狗场「bc狗」跟踪。

## 只处理最新一单

- 斗狗场订单区「待投/最新」= 最新一张票；历史单只读不动。
- 一张串光票 = **一个订单**（8 腿合成 8串1），不要拆成 8 单逐场下单。

## 演练 / 复盘模式

- 贴来已截止比赛的票（如 26091 期 08-31 已完赛场次）：只做 解析 → 编号行定位 →
  已选核对，不投注；结果看斗狗场结算即可。
- 今日场次随机演习：按 5包3胆 随便挑 8 场点选（3 场单选 + 5 场全包）。

## 实操提示（踩过的坑）

- 页面索引快照有上限（bridge maxInteractiveItems=60）：中部行（40-139）的按钮
  索引会被省略，**先滚动到目标行再快照**拿索引。
- **紧凑核对**：勾选的场次如果离当前视口太远（比如编号 90），不用逐行翻页——
  用页面的「看已选」已选汇总视图核对，选中场次会紧凑列出来（红色已选 + 设胆勾选都在）。
- 跨站操作（okooo↔dsh）可能弹一次浏览器授权，点 Allow once 后本会话不再问；
  偶发单次点击超时是授权未响应，重试即可。
