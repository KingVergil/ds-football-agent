# 全部结算（结算流）

薄壳架构下，固定流（含结算）**没有 LLM 工具**：执行入口只有斗狗场表单
（每狗行的「🧾 结算」按钮 → `POST /ds-run {dog, func:"settle", day}` → 插件直接
spawn `python -m src.bridge`，python 引擎只认完场比分结算并写角色文件）。

## 你该做什么

1. 用户要「全部结算」时，引导他在斗狗场逐狗点「🧾 结算」（或回放/定时任务内自动结算）。
2. 结算结果看任务记录：每狗 结算数 / 命中 / 未中 / 走水 / PnL / 余额。
3. 不要用 bash/文件操作复刻结算；你的工具面板只有只读数据工具。
4. `bc狗` 结算同按钮分流到 `src.beidan_parlay_dog.settle`：按北单开奖
   `result + spvalue` 结算（每腿命中即中、奖金 = 各腿开奖 SP 连乘 × 2 元 × 65%），
   结算后自动做腿级因子反思（`reflect=True`）。

> 结算 + 因子归纳/退役的完整日流程由回放模式（/ds-replay，插件侧逐日编排）承担。
