# 全部结算（结算流）

对 7 只单关狗（不含串关2狗）并行结算。串关2狗归 Python 侧，跳过。

## 步骤

1. **结算流**：调 `ds_settle_all(parallel=7)` —— 纯 JS 并行结算 7 只狗（只认 state==6 完场比分），每狗进度写入任务状态，无任何 LLM 介入。
2. **不需要**手动逐狗 `ds_settle_js` / 反思 / 因子归纳——那些属于因子流（`ds_factor_flow`）。

## 说明

- 结算 + 反思 + 因子归纳/退役的完整日流程见回放模式（`ds_replay`）；独立因子操作走 `ds_factor_flow`。
- 若某狗 `unsettled=0`（无待结算单），结算流直接跳过，进度照常推进。
